Real-Time Face Distance & Angle Estimation

A single webcam is all it takes. Using MediaPipe's face detector and simple pinhole-camera geometry, this app estimates how far you are from the screen and how far off-center you're standing — entirely in real time, running locally on your laptop.

Start Detection
Depth Estimation

Uses the classic Z = f×W / wpx similar-triangles formula, calibrated to your own webcam for accurate real-world distance in meters.

Angle Detection

Computes horizontal deviation from the camera's optical axis with θ = arctan((x-cx)/f), flagging Left / Center / Right.

History & Analytics

Every detection is logged to SQLite with a face thumbnail, then visualized with Chart.js on the analytics dashboard.

About the Project

FaceX is a beginner-friendly computer vision system. It demonstrates how classical camera geometry (the pinhole camera model) can be combined with a modern, lightweight face detector to solve a practical depth & orientation estimation problem — without any specialized depth hardware, purely from a single RGB webcam.

  • Runs 100% locally, no cloud dependency
  • Simple, well-documented Python codebase
  • One-time calibration for accurate real-world units
