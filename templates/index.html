Real-time AI Detection

Detect any ball, in real time,
right from your webcam.

BallVision is a computer-vision monitoring system that uses YOLOv8 and OpenCV to locate a ball in a live video feed - tracking its position, confidence, and speed while logging every detection for later review. Built for a hackathon, designed like a production dashboard.

Start Detection View Analytics

How it works

1. Capture Webcam / Video
2. Detect YOLOv8 + OpenCV
3. Log SQLite Database
4. Visualize Live Dashboard

Core Features

Precise Localization

Bounding box + center-point coordinates for every detected ball, updated every frame.

Real-time FPS

Optimized with YOLOv8-nano to target 20+ FPS on a standard laptop CPU.

Detection History

Every detection is logged to SQLite with a thumbnail, searchable in a live table.

Colour Filtering

Optionally restrict detection to a specific ball colour (orange, green, yellow, red).

Webcam or Video

Switch seamlessly between a live webcam feed and an uploaded video file.

CSV Export

Export the entire detection history for further analysis in Excel or Sheets.

Technologies Used
Python OpenCV YOLOv8 Flask SQLite HTML5 CSS3 JavaScript Bootstrap 5 Chart.js
